# PyTorch is NOT listed here on purpose.
#
# The CUDA build does not come from PyPI, so `pip install -r requirements.txt`
# would silently pull the CPU-only wheel and every model would train on CPU.
# Install it separately first (see README), then install this file:
#
#   pip install torch --index-url https://download.pytorch.org/whl/cu124
#
# Verified working on this machine: torch 2.6.0+cu124, Python 3.12, Windows x64,
# RTX 4050 Laptop (6 GB VRAM, sm_89, driver 581.32), fp16 autocast confirmed.
# ---------------------------------------------------------------------------
#
# WINDOWS SMART APP CONTROL - why these versions are pinned exactly.
#
# This machine runs Smart App Control in Enforced mode, which refuses to load
# compiled extension modules (.pyd) that lack an established reputation. The
# newest releases of pandas and scikit-learn are blocked on install day with:
#
#   ImportError: DLL load failed while importing interval:
#   An Application Control policy has blocked this file.
#
# The versions below are older and widely deployed, so they load fine. Do not
# bump them casually - `pip install -U pandas` can break the whole project on
# this machine. numpy is capped because pandas 2.2.x needs numpy < 2.2.
# ---------------------------------------------------------------------------
